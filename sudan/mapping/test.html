Test mode

For the Durable Solutions Unit. Test mode shows the Sign in button and makes this browser send projects straight to the new review queue. Everyone else sees the hub as it is, and nothing changes on the map until you publish from the Manage pages.

Test mode is in this browser.

What to test
  1. Add one project: fill in the form, add a photo, press Send.
  2. Add multiple projects: upload a filled copy of the Excel template.
  3. My submissions: check the status and the Add photos button.
  4. Sign in (top right): type your work email, then the 6-digit code from the email. Your initials then open Manage all projects, the review queue and the approved editors. Use Do not publish for test projects, so they do not appear on the map.

When everything works, the form is switched on for everyone by setting the back end address in the site settings.
